# VALKIRIA GYM — DESIGN SYSTEM

## Objetivo
Crear una presencia digital premium, intensa, moderna y deportiva para Valkiria Gym. La web debe sentirse diseñada a medida, no como una plantilla genérica ni como una demo de IA.

## Personalidad de marca
- Fuerza
- Disciplina
- Energía
- Comunidad
- Profesionalismo
- Movimiento

## Estética
- Base oscura
- Alto contraste
- Tipografía grande y sólida
- Fotografía real del gimnasio
- Animaciones fluidas y controladas
- Mucho aire visual entre secciones

## Paleta
- Fondo principal: #080808
- Fondo secundario: #111111
- Texto principal: #F7F7F7
- Texto secundario: #B6B6B6
- Acento: #E10078
- Acento hover: #FF2A93
- Bordes: rgba(255,255,255,.12)

## Tipografía
Usar una sans-serif moderna y simple.
- Headlines: peso 800/900
- Subtítulos: 600/700
- Body: 400/500
- Evitar tipografías futuristas difíciles de leer

## Hero
- Debe ocupar gran parte del primer viewport.
- Imagen o video real del gimnasio.
- Zoom cinematográfico lento, no agresivo.
- Overlay oscuro para legibilidad.
- CTA primario visible.
- Evitar cards flotantes genéricas.

## Secciones aprobadas
1. Hero
2. Sobre Nosotros
3. Instalaciones
4. Planes
5. Horarios
6. Reseñas
7. Frases motivacionales
8. Contacto / WhatsApp / Instagram
9. Footer

## Instalaciones
- Carrusel o galería horizontal.
- Usar fotos reales.
- No ubicar el carrusel de reseñas inmediatamente al lado de este carrusel.

## Reseñas
- Solo reseñas reales.
- Tarjetas simples.
- Mostrar nombre, puntuación y texto breve.
- No inventar testimonios.

## Planes
- Claros y comparables.
- Un plan destacado como recomendado solo si el gimnasio lo aprueba.
- CTA directo a WhatsApp.

## Animaciones
Permitidas:
- Reveal al scroll
- Fade + translate suave
- Parallax leve
- Zoom de hero
- Microinteracciones en botones
- Hover sutil en cards
- Marquee o ticker muy controlado

Evitar:
- Exceso de 3D
- Efectos que dificulten la lectura
- Gradientes violeta/azul típicos de interfaces IA
- Brillos neón por todas partes
- Animaciones que muevan elementos constantemente
- Scroll-jacking

## Responsive
Diseñar mobile-first.
Breakpoints de referencia:
- Mobile: < 768px
- Tablet: 768–1023px
- Desktop: >= 1024px

## Accesibilidad
- Contraste AA como mínimo.
- Texto legible.
- Focus visible en controles.
- Imágenes con alt descriptivo.
- No depender solo del color.

## Rendimiento
- Priorizar WebP/AVIF.
- Lazy-loading fuera del hero.
- No cargar librerías pesadas si CSS resuelve el efecto.
- Evitar videos enormes sin compresión.

## Elementos bloqueados
NO modificar sin aprobación:
- Logo
- Colores corporativos finales
- Fotografías originales
- Orden aprobado de secciones
- Información comercial
- Links de WhatsApp, Instagram y ubicación
- Textos finales aprobados

## Regla para asistentes de IA
Antes de hacer cambios visuales:
1. Leer este archivo.
2. Preservar los elementos bloqueados.
3. Cambiar solo lo solicitado.
4. No rediseñar áreas no relacionadas.
5. Mantener consistencia con el sistema visual.

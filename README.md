# Valkiria Gym

Maqueta web profesional para Valkiria Gym.

## Stack
- Next.js
- React
- CSS moderno
- Deploy recomendado: Vercel

## Desarrollo local

```bash
npm install
npm run dev
```

Abrí `http://localhost:3000`.

## Estructura

- `app/` — páginas y estilos
- `public/` — imágenes, logo y assets
- `DESIGN.md` — sistema visual y reglas del proyecto

## Assets a cargar

Guardá en `public/`:
- `logo-valkiria.png`
- `hero-valkiria.jpg`
- `instalacion-1.jpg`
- `instalacion-2.jpg`
- `instalacion-3.jpg`

## Enlaces pendientes

En `app/page.jsx` reemplazá los placeholders de WhatsApp, Instagram y Google Maps por los enlaces oficiales.

## Deploy

1. Subir cambios a GitHub.
2. Importar este repositorio en Vercel.
3. Deploy automático desde la rama `main`.

> El sitio debe respetar siempre las reglas de `DESIGN.md`.
